# task-manager
Автор: Синилкин Максим Владимирович
Язык: Python 3.9+
Технологии: Tkinter, json, random, unittest

Это графическое приложение для управления персональными задачами. Оно позволяет создавать, редактировать, фильтровать и удалять задачи, сохраняя их в локальный файл для постоянного хранения.

📦 Описание проекта
Проект представляет собой кроссплатформенное десктопное приложение с графическим интерфейсом (GUI). Основная цель — закрепить навыки разработки на Python, включая работу с библиотекой Tkinter, сериализацию данных в JSON, валидацию пользовательского ввода и написание модульных тестов.

✅ Ключевые особенности:
Интуитивный интерфейс: Простое управление через поля ввода и кнопки.
Постоянное хранение данных: Все задачи сохраняются в файл data/tasks.json и автоматически загружаются при запуске программы.
Гибкая фильтрация: Возможность быстро находить задачи по названию или приоритету.
Надежная валидация: Защита от ввода некорректных данных (пустое название, неверный приоритет).
Автоматическое создание данных: Программа сама создает необходимые файлы и папки при первом запуске.
🛠️ Технологии и архитектура
Python: Основной язык программирования.
Tkinter: Стандартная библиотека Python для создания графического интерфейса.
json: Встроенная библиотека для работы с форматом JSON (сохранение и загрузка задач).
random: Используется для генерации уникальных идентификаторов (ID) для каждой задачи.
unittest: Фреймворк для написания и запуска автоматических тестов, проверяющих логику приложения.

👨‍💻 Как пользоваться приложением
Интерфейс программы разделен на три логических блока: ввод данных, управление и список задач.

1. Добавление новой задачи
В поле «Название» введите суть задачи (например, «Сдать отчет»).
В поле «Описание» можно добавить подробности (необязательно).
В поле «Приоритет» введите число от 1 до 5, где 1 — самый низкий, а 5 — самый высокий приоритет.
Нажмите кнопку «Добавить».
Задача мгновенно появится в списке ниже и будет сохранена на диск.
2. Фильтрация задач
Вы можете быстро найти нужные записи в списке:

Фильтр по названию: Введите ключевое слово в поле «Название» (например, «отчет») и нажмите кнопку «Фильтровать по названию». В списке останутся только задачи, содержащие это слово.
Фильтр по приоритету: Введите число от 1 до 5 в поле «Приоритет» и нажмите кнопку «Фильтровать по приоритету». Покажутся только задачи с указанным уровнем важности.
3. Удаление задачи
Кликните один раз по задаче в списке, чтобы выделить ее.
Нажмите кнопку «Удалить».
Выделенная задача будет немедленно удалена из списка и из файла данных.
📁 Структура проекта
Проект организован по модульному принципу для удобства чтения и поддержки:

app.py — основной файл, содержащий логику приложения и код графического интерфейса.
data/ — папка для хранения файла с данными (tasks.json). Создается автоматически.
tests/ — папка с модульными тестами (test_app.py).
.gitignore — файл, указывающий Git, какие файлы и папки не нужно отслеживать (например, временные файлы Python).
README.md — этот файл с описанием проекта.
🧪 Тестирование
В папке tests/ находится файл test_app.py, который содержит проверки для функций загрузки и сохранения данных. Это гарантирует, что основная логика работы с файлами функционирует правильно. Запустить тесты можно командой из инструкции выше.
